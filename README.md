💼 终端产品全维度研判平台 (Strategy Hub)
这是一款专为产品营销经理 (PMM) 打造的数字化作战工具。它将零散的社交媒体语料（UGC）转化为“高管准入级”的内参报告，支持单品深度复盘与跨品牌战略攻防研判。

🌟 核心能力升级
📡 自动化情报取证：输入产品关键词，系统自动生成小红书（痛点挖掘）、微博（舆情翻车）、抖音（差评视频）的精准搜索链路，彻底解决“找素材难”的问题。

⚔️ 战略攻防双模式：

单品深度研判：针对本品（如 vivo X300U）进行 360° 舆情穿透。

竞品对比阵列：支持本品与对标竞品（如 OPPO Find X 系列、华为 Pura 系列）的横向攻防对比。

🧠 纯净式 AI 研判引擎：深度集成阿里云 DashScope 模型（如 DeepSeek-V3），采用 Temperature=0 的绝对锁定策略，确保分析结果 100% 基于语料事实，严禁 AI 幻觉。

📜 专家级内参渲染 (NEW)：

自动清洗：智能过滤 Markdown 符号、乱码及多余修饰符。

专业排版：内置 CSS 引擎，自动生成包含“问题反馈矩阵”和“尖锐原声直击”的结构化报告。

一键离线备份：支持导出 Base64 编码的 HTML 报告，完美兼容浏览器 PDF 打印引擎，保持大厂内参的严谨质感。

🛠️ 技术实现
Frontend: Streamlit (提供响应式交互界面)

Engine: Python + Requests + Regex (实现高效数据清洗与 API 交互)

UI/UX: HTML5 + CSS3 (定制化专业报告模版)
